## How to Work Here

### Before writing any post
1. Read `writing-style.md` fully — it defines voice pillars, what to avoid, and LinkedIn post structure rules.
2. If the topic is new, run the grill-me flow to extract personal details before drafting.

### Post structure rules (from writing-style.md)
- Hook: question, contradiction, or quiet observation — never a humblebrag
- Short paragraphs, one idea each
- No bullet-point dumps
- End with reflection, not always a CTA
- Personal but not oversharing; specific but not name-dropping

### Phrases to never use
"excited to announce", "humbled and grateful", "thrilled to share"
